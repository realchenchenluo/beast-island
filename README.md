# 变身岛 · 3D 大世界 H5 试玩

[▶ 打开在线试玩](https://realchenchenluo.github.io/beast-island/)

这是《变身岛》的 H5 试玩版：3D 小岛、34 个可变身生物、自动战斗、战利品转盘、12 层高塔、3D 场景内农田、装饰、背包、图鉴和商店。

## 这版更新

- **战斗/备战/结果/图鉴**：动物图全部换成从 3D 模型渲染的 45° 英雄图；相机按“模型 + 孔雀扇 / 白泽翼 / 九尾 / 龙翼”的整体包围盒取景，新增逐像素 QA（空图、四边裁切检查），九尾狐浮空金点已移除。
- **大世界**：连续土路带 + 中心石砌广场，路径灯笼、路牌、长椅、石堆和花丛；分层阔叶树/松树/棕榈、苔藓岩石、纹理草簇、花/蕨/芦苇/蘑菇/倒木/树桩/卵石；软阴影、水波、岸边泡沫、渐变天空、太阳光晕、蝴蝶和花粉。植被和道具用最小间距/类别排斥的约束摆放（WFC 思路），减少互相穿插。
- **操作栏**：6 个图标 Dock（战斗剑 / 高塔 / 农田 / 背包 / 图鉴 / 装饰），战斗按钮金色扫光 + 粒子点，命中带火花。

## 操作

- 左下角摇杆或 `WASD` / 方向键移动；拖动画面旋转相机。
- 右下角：战斗 / 高塔 / 农田 / 背包 / 图鉴 / 装饰。
- 农田靠近田块出现金色高亮圈和操作面板：种田、浇水、施肥、铲除；成熟后变为收获。

> 这是浏览器试玩版，不是小红书小工具验收版。浏览器没有小工具的 Storage API，**存档只在当前会话，刷新会重新开始**。  
> 正式提交请下载 [变身岛.zip](./变身岛.zip)，上传创服平台，并在平台模拟器、Android 真机和 iOS 真机上验证。
