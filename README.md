# 变身岛 · 3D 大世界 H5 试玩

[▶ 打开在线试玩](https://realchenchenluo.github.io/beast-island/)

这是《变身岛》的 H5 试玩版：3D 小岛、34 个可变身生物、自动战斗、战利品转盘、12 层高塔、3D 场景内农田、装饰、背包、图鉴和商店。

## 这版新增

- **普通攻击 + 技能蓄势**：普通攻击更常出现，每次 +25 气势；气势满 100 后才进入技能判定（基础 70%，受属性/残血影响，45%–92%）。战斗血条下有气势条，普通/技能日志分色，技能命中有金色闪光。
- **第一次上岛指导**：首次进入世界显示 4 步引导（欢迎、移动、普通攻击/技能、农田与整岛），可跳过；完成后写入 `guideSeen`，小工具里之后不再出现。浏览器试玩无 Storage，刷新会重开。
- **摆放优化**：10 个树丛中心 + 12 棵沿路棕榈；12 个草甸中心 + 路边花草带；6 个岩石群；蘑菇/蕨类贴近树丛；全部带最小间距/类别排斥（WFC 约束思路）。
- **战斗/备战/结果/图鉴**：使用 3D 模型英雄渲染图；相机按模型 + 孔雀扇/白翼/九尾/龙翼整体取景，逐像素 QA 防裁切/空图。
- **大世界**：连续土路 + 中心石砌广场、路径灯笼/路牌/长椅/石堆/花丛；分层树、纹理草簇、花/蕨/芦苇/蘑菇/倒木/树桩/卵石；软阴影、水波、岸边泡沫、渐变天空、太阳光晕、蝴蝶和花粉。
- **操作栏**：6 个图标 Dock（战斗/高塔/农田/背包/图鉴/装饰），战斗按钮金色扫光+粒子，命中火花。

> 这是浏览器试玩版，不是小红书小工具验收版。浏览器没有小工具的 Storage API，**存档和首次引导只在当前会话，刷新会重置**。  
> 正式提交请下载 [变身岛.zip](./变身岛.zip)，上传创服平台，并在平台模拟器、Android 真机和 iOS 真机上验证。

## 模型与素材

- Polyfork：CC BY 4.0，<https://polyfork.dev>；Poly by Google / Poly Pizza：CC BY 3.0（模型页和作者见 [assets/credits.json](./assets/credits.json)），鲸鱼作者 sirkitree。
- 3D 英雄渲染图由本项目用 three.js 从包内模型生成；Lucide 图标参考（ISC）；three.js r120（MIT）。
- WFC（mxgmn/WaveFunctionCollapse）和 RetopoFlow（CGCookie）分别是生成算法与 Blender 拓扑插件，不能直接作为 H5 运行时依赖；本项目采用其约束思路和可自动化的渲染 QA。
- Blockbench 是建模编辑器，ParticleEffectForUGUI 是 Unity UGUI 插件；对应建模/UI 粒子效果由本地流程和 CSS 实现。
