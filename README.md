# 万灵屿（3D 大世界版）

一个离线 H5 小工具：随机变身成各种生物，从一座只有祭坛的空岛开始，用战斗赚金币，逐步建设商店、农田、花园和小屋，再自由种出属于自己的 3D 小岛。

## 核心循环

1. 新存档上岛时，岛上**只有岛、土路、水塘和战斗祭坛**；没有预置的花草树木、商店、农田和房屋，只有三块挂着「可建设」木牌的预留地。
2. 去祭坛或点右下角「战斗」进入备战。双方传送到擂台自动战斗；结果可能是战力碾压、优势取胜、极限险胜、全面溃败、惜败或憾负，也可能「以弱胜强」。
3. **胜利后用战利品转盘抽奖励**，可以转动，也可以「一键跳过」直接抽取；转盘有「谢谢参与」，所以不是每场战斗都有奖励。失败没有转盘。
4. 胜利会随机变成新生物；失败则装备槽 +1（最多 6 格），然后选择随机变身或保持形态。胜利后装备槽重置为 2 格。
5. 用金币打开「建设」页解锁花园、杂货铺、小农田、装饰工坊、小屋与图鉴、战斗高塔；物理建筑会真的出现在预留地上，快捷栏也会随之增加入口。
6. 解锁花园后可以自由种草、野花、蕨、蘑菇、芦苇、卵石、灌木、阔叶树、松树、棕榈和岩石，点已有植物即可拔除重来。
7. 解锁农田后可以种三棵增益树：战意树、铁壁树、疾风树。摘果获得一次性战斗增益，带着增益去祭坛打架。
8. 金币足够时，可以在战斗准备页或图鉴里直接指定变身成任意生物；价格按稀有度阶梯上涨，是后期最大的金币消耗点。

## 3D 操作与一键入口

- 左下角摇杆或 `WASD` / 方向键移动。
- 拖动画面旋转第三人称相机；滚轮 / 双指缩放。
- 点击地面自动寻路；点击建筑走到入口并自动互动。
- 右下角快速按钮是**按解锁状态动态生成**的：开局只有 **战斗 / 建设 / 背包**；解锁后依次加入 **种植 / 农田 / 高塔 / 装饰 / 图鉴**，最多 8 个，排成两行。
- 「战斗」一键进入普通战斗；祭坛仍是岛上的地标，走到旁边也能互动。
- **农田是 3D 场景内交互**：从东侧两格宽的栅栏门走进农场，靠近田块会出现金色高亮圈和操作面板；也可以直接点「农田」进入。未解锁时不会出现农场面板。
- 「种植」打开自由种植抽屉：选植物后点击附近草地种下，点已有植物拔除；未解锁花园时会跳到建设页的花园卡片。
- 「装饰」打开装饰抽屉：选中装饰后点击附近草地摆放，点击已摆放装饰收回；未解锁时同样跳转建设页。
- 战斗准备页会显示当前战斗增益的层数和效果，并提供「指定变身」入口；图鉴页右上角也能直接打开。

## 空岛开局与建设

- 新存档起始金币 **40**，解锁价格：花园 30、杂货铺 40、小农田 80、装饰工坊 70、小屋与图鉴 120、战斗高塔 150。
- 花园是最便宜的解锁项，买下后就能免费无限铺草簇，其他植物 1–35 金币不等；草簇免费，野花 2、蕨草 4、蘑菇 3、芦苇 3、卵石 1、灌木 12、阔叶树 30、松树 35、棕榈 25、岩石 18。
- 建筑解锁后会在原来的预留地位置重建：商店、农田和小屋出现在岛上，祭坛不变；未解锁时是带木牌、木桩和围绳的工地，走近互动会直接打开对应的建设卡片。
- 建设页显示所有项目、价格、说明和已解锁状态；金币不足时按钮禁用，并提示去祭坛战斗。
- 旧存档如果没有 `unlocks` 字段，会自动视为全部解锁，原有玩家的商店、农田、装饰和进度不受影响；重新开始会回到空岛状态。
- 全岛植物上限 **320**，花园抽屉实时显示「已种 N / 320」。

## 自由种植与真实感

- 可种 11 类：草簇、野花、蕨草、蘑菇、芦苇、卵石、灌木、阔叶树、松树、棕榈、岩石；草地和沙地都可种植，小路、水面、建筑占地和已有植物会被拒绝。
- 植物按小岛网格保存，退出重进、离开世界再回来都会恢复；实心植物（灌木、三种树、岩石）会真正改变寻路碰撞，拔除后恢复。
- 草地纹理重做：多层草叶、三叶草、枯土、小石子和低频色斑；土路重做：五层泥土渐变、车辙、土块、压实石子、细砂、裂纹和从两侧长进路面的草。
- 草簇从 2 层交叉面改成 4 层交叉面 + 贴地草基，草叶更密、更宽，带草籽、枯叶和接地阴影。
- 野花改为多花头、花瓣环、花苞和叶片；蕨草改为九条弧形羽叶；蘑菇有大小群落、菌盖斑点和苔藓底座。
- 阔叶树、松树、棕榈和灌木在低模几何外加了**贴合树冠表面的叶片卡片**：阔叶树叶簇、松针、棕榈叶和灌木叶各有独立程序化纹理，轮廓不再是一个个硬方块；阔叶树冠增加更多小叶团，松树增加九层枝层和小枝，棕榈改为弯曲树干和放射状叶片。

## 增益树与战斗增益

- 农田现在有 6 种可种物：胡萝卜、南瓜、星星果，以及战意树、铁壁树、疾风树。三种增益树都是 3D 小树，成熟后在田里会结出对应颜色的果实。
- **战意树**：4 分钟成熟，4 种子 / 2 清水，收获 30 金币 + 战意果；下一场战斗己方战力 +20%。
- **铁壁树**：5 分钟成熟，5 种子 / 3 清水，收获 40 金币 + 铁壁果；下一场战斗对手战力 -20%。
- **疾风树**：6 分钟成熟，6 种子 / 3 清水，收获 50 金币 + 疾风果；下一场战斗技能释放概率 +12%。
- 摘果时直接获得增益，不需要再进背包使用；每种增益最多囤 5 层，每打一场消耗一层。多棵增益树可以叠不同效果，也可以把同一种增益攒到 5 层再连续挑战。
- 护盾卡、双倍卡与三种果实可以同时生效；战斗准备页会列出所有生效增益。
- 施肥仍然会让增益树的生长时间减半；铲除会损失投入，不返还种子和清水。

## 金币指定变身

- 战斗准备页的「指定变身」或图鉴右上角的「指定变身」可以打开 34 种生物的选择面板。
- 价格严格按稀有度：**普通 2,000 · 稀有 6,000 · 史诗 15,000 · 传说 50,000 · 神话 200,000** 金币。
- 选中后会二次确认，显示扣除前后余额；金币不足时直接提示还差多少，不会误扣。
- 指定变身会记录到图鉴（变为已拥有）和最近变身记录，但**不会增加也不会消耗** 300 次传说 / 2000 次神话随机保底。
- 这是后期金币的主要去向，普通和稀有形态相对容易攒到，传说和神话需要长期经营农田、战斗和高塔。
- 价格是按稀有度统一，不按单只生物战力定价；同一稀有度内选强力或喜欢的形态价格相同。

## 视觉风格

- **墨金主题**：界面改为深墨色 + 旧金色，标题使用宋体/衬线，按钮与面板改为低圆角、细边框，替换原来的粉彩糖果风。
- 战斗擂台是黄昏色调；战利品转盘改成深色宝石色盘；首屏、加载态和无 WebGL 兜底也同步为暗色。
- 3D 世界角色来自 Polyfork / Poly by Google 等的低多边形动物；战斗、备战、结果和图鉴统一使用从同一批 3D 模型渲染的 45° 英雄图，不再使用 Fluent 表情头像。

## 普通攻击与技能

- 每次行动由“蓄势算法”决定：普通攻击 +25 气势，气势满 100 后才进入技能判定；普通攻击出现得更多。
- 气势满后技能概率约为 70%，并受属性优势（+8%）、敌方低血量（+7%）、自身低血量（-12%）影响，最终限制在 45%–92%。
- 普通攻击使用较低倍率，技能使用较高倍率；会心、背水一战对两者都适用。
- 战斗 UI 的血条下增加气势条，普通/技能日志使用不同颜色；技能命中带额外金色闪光。

## 第一次上岛指导

- 新用户第一次进入世界（`guideSeen=false`）会出现 6 步引导：空岛/祭坛、移动与互动、去祭坛赚第一笔金币、用金币建设、花园自由种植、农田增益树。
- 支持上一步、下一步、跳过；点“开始冒险”或“跳过”后写入 `guideSeen=true`，之后不再出现（小工具 Storage 持久化）。
- 引导文案明确说明“岛上没有现成花园、商店和农田”，不会再把未解锁入口当成已有功能介绍。
- H5 浏览器试玩没有小工具 Storage，刷新会重新开始，所以引导会在刷新后再次出现；这是浏览器试玩的限制。

## 大世界摆放

- 空岛开局不再自动生成任何树木、花草、岩石或路牌；唯一的绿色来自地形草地，`map.scenery` 为空，全部植被由玩家种植。
- 岛形、池塘、土路和建筑预留地仍由种子生成，保证每局地图一致、路径可寻路；预留地只放工地木牌，不解锁就不会出现建筑。
- 种植合法性与摆放手感：必须站在 10 格以内，不能占用小路/水面/建筑/装饰/已有植物；实心植物会进入寻路碰撞，可点击拔除。玩家拥有完全的布局自由，不再用自动成簇算法限制位置。

## 战利品转盘

- 每次**战斗胜利**获得 1 次转盘机会；失败没有。
- 8 个扇区：谢谢参与、金币、大金币、种子、清水、装备、装饰、道具卡。
- 概率大致：谢谢参与 22%、金币 24%、大金币 10%、种子 12%、清水 12%、装备 8%、装饰 7%、道具卡 5%。
- 「双倍卡」会让金币/种子/清水奖励翻倍。
- **一键跳过**直接抽奖并立即显示结果，不等转盘动画。
- 装备和装饰按稀有度加权掉落；装饰等级越高越难获得。

## 战斗高塔

- 共 12 层，每层对手战力按玩家当前战力递增。
- 每层胜利自动进入下一层，并获得一次战利品转盘；失败则本次闯关结束，从第 1 层重新开始。
- 最佳通过层数永久保留；高塔界面显示每一层的预计战力和通过状态。
- 高塔与普通战斗共用变身、装备、属性和道具卡系统。

## 生物与概率

共 **34 种**生物：

- 普通：兔子、小猪、绵羊、山羊
- 稀有：奶牛、狐狸、狼、猴子、海龟、鹰、**小刺猬**
- 史诗：长颈鹿、鳄鱼、熊猫、棕熊、仙鹤、孔雀、章鱼、鲨鱼
- 传说：老虎、狮子、大象、麒麟、白泽、九尾狐、穷奇、白虎、玄武、朱雀
- 神话：青龙、凤凰、鲲、烛龙、应龙

随机变身概率约：普通 55% · 稀有 30% · 史诗 14% · 传说 0.8% · 神话 0.02%。
连续变身会积累机缘：**300 次必得传说，2000 次必得神话**。图鉴记录已变身次数、已遇见生物和最近 30 条变身记录，小刺猬也在图鉴中。

## 属性克制

天克地，地克水，水克天；灵属性不受克制，也不克制其他属性。克制方伤害 +25%，被克方伤害 -15%。

## 装饰等级

- 装饰分 Lv.1 普通、Lv.2 稀有、Lv.3 史诗、Lv.4 传说，等级越高越难获得、繁荣度越高。
- 世界装饰抽屉、背包和转盘结果都会显示装饰等级。
- 12 种装饰：椰子树、花丛、木栅栏、珊瑚摆件、石灯笼、秋千、篝火、稻草人、小木屋、小风车、贝壳喷泉、勇者雕像。

## 农田 / 商店 / 装备 / 图鉴

- 农田 4 块地，按真实时间生长，3D 世界同步显示作物状态；普通作物之外还能种三棵战斗增益树。
- 进入农场、靠近田块后，操作面板直接提供：**种田 / 浇水 / 施肥 / 铲除**；成熟时「种田」位置变为「收获」。
- 种田可选胡萝卜/南瓜/星星果；浇水消耗清水；**施肥消耗肥料，每株作物只能施一次，生长时间减半**；铲除需要二次确认，且不返还投入。
- 肥料在杂货铺购买（2 份 24 金币），初始有 2 份，操作面板顶部实时显示种子/清水/肥料数量。
- 点「离开」或从栅栏门走出农场，快捷按钮恢复；农场不再是独立页面。
- 杂货铺用金币购买种子、清水、道具卡、随机装饰和随机装备。
- 武器/护甲/饰品提供永久战力；装备槽规则见上。
- 道具卡：刷新卡、强化卡、护盾卡、双倍卡。
- 图鉴包含全部 34 种生物，展示稀有度、属性、战力、技能、已变身次数和最近变身记录。

## 3D 动物模型（34 个形态全部 3D）

现在 3D 世界里 **34 个形态全部有实体模型**，不再有“老虎/熊猫/小刺猬还是头像精灵”的情况。所有模型都去掉了骨骼和动画，只保留绑定姿态，以便离线小工具加载。

### 原本缺失的 10 个

- **直接模型**：老虎、熊猫、猴子、鹰、小刺猬来自 Poly by Google / Poly Pizza 的低模（CC BY 3.0），带贴图或调色板纹理。
- **白虎**：用同一只老虎模型 + 专门处理的白色虎纹贴图（保留黑色条纹）。
- **仙鹤**：Great egret 长腿鸟模型 + 红色头顶、黑色颈部/面部特征，做成丹顶鹤外观。
- **孔雀**：Pheasant 雉鸡模型 + 程序化绘制的孔雀开屏扇（9 根羽眼）+ 蓝绿色贴图。
- **凤凰 / 朱雀**：Pheasant 模型 + 火焰色贴图 + 火焰扇形尾屏；朱雀更偏朱红，凤凰偏金橙。
- **鲲**：鲸鱼模型 + 金色龙须、金色背鳍和两片巨型鳍翼，做成巨型海兽/鲲鹏感。
- **小刺猬**：Poly by Google 刺猬模型，已在图鉴和 3D 世界都能看到。

### 6 个神话形态不再用近缘凑数

- **麒麟**：金色马形基底 + 金色龙角、龙须、鬃毛、鳞片与尾穗，专门的麒麟金色贴图。
- **白泽**：白色狮形基底 + 金色鹿角、额间第三眼、白金双翼。
- **九尾狐**：狐狸基底 + 8 条额外尾巴（连同本体尾巴共 9 条），白/银/金渐层尾尖。
- **穷奇**：老虎基底 + 紫色双翼 + 暗紫虎纹调色，明确是“有翼之虎”。
- **玄武**：黑绿色龟形基底 + 环绕龟甲的青绿色蛇身与蛇头，龟蛇合体。
- **朱雀**：朱红色雉鸡基底 + 朱红火焰扇尾，与凤凰共用基底但使用不同贴图和火焰色。

### 模型数据怎么进包

- 源模型来自 Polyfork（CC BY 4.0）与 Poly by Google / Poly Pizza（CC BY 3.0）。构建脚本只保留绑定姿态的位置、法线、顶点色/UV，去掉骨骼、蒙皮和动画。
- 模型分成两种紧凑格式：PFM1（顶点色）和 PFM2（索引 + UV + 可选贴图）。先量化成字节流，再编码进**普通 RGB PNG** 资源像素；不把 `.glb`、Base64 或大型数组塞进 JS。
- 贴图单独保存为 `assets/models/tex-*.png`，构建时从 GLB 提取并缩放（最大 256px）；白虎、孔雀、凤凰、朱雀、白泽、麒麟使用构建期生成的调色变体。
- 运行时按当前形态用包内 `Image` 懒加载模型 PNG 和贴图，离屏 canvas 还原字节后构建 three.js BufferGeometry；模型加载前/失败时用同一形态的 3D 英雄渲染图作为精灵兜底，不会白屏。
- 当前 `models/` 总共 29 个基础模型 + 12 张纹理，约 1.8MB；模型和纹理都按形态懒加载，不阻塞首屏。

## 视觉与素材

- **3D 动物**：Polyfork（CC BY 4.0）+ Poly by Google / Poly Pizza（CC BY 3.0）低模，来源与模型页逐条写在 `assets/credits.json`。已去除骨骼/动画并量化；白虎、孔雀、凤凰、朱雀、白泽、麒麟使用构建期调色贴图，神话形态另有程序化角/翼/尾/蛇身等特征。
- **战斗/备战/结果/图鉴里的动物图**：全部换成 **3D 模型英雄渲染图**（`assets/renders/<form>.png`，正侧 45°、元素色圆台、透明底），不再是 Fluent Emoji 头像；加载失败时用同一张渲染图作为精灵兜底。
- **大世界美术**：地形改为平滑顶点色 + 三层细节纹理（草叶/三叶草/土斑/小石子）；土路是 5 层泥土纹理的连续路带，有车辙、土块、压实石子、细砂、裂纹和路缘草；开局没有石砌广场、路牌、灯笼或长椅。植物全部由玩家种植：4 层交叉草簇带贴地草基，野花有多花头和花苞，蕨草是弧形羽叶，蘑菇成小群落，树木和灌木在低模几何外叠加贴合表面的叶片卡片（叶簇/松针/棕榈叶），树石都有软阴影。水面有波纹和岸边泡沫，天空是渐变穹顶 + 太阳光晕，场景里保留蝴蝶和花粉。
- **英雄图与取景**：34 张英雄图全部按“模型 + 孔雀扇/白泽翼/九尾/龙翼”的整体包围盒取景，四边留安全边距；九尾狐原先浮空的金色尾尖已移除。渲染 QA 逐像素检查非空和四边不裁切。
- **大世界摆放约束**：树木、灌木、岩石、草花和道具不再纯随机堆叠，增加了最小间距与类别排斥（参考 WFC 的约束一致性思路，没有直接运行 C#/Haxe 版 WFC），避免树冠互相穿模、草花堆在同一个点上。
- **操作栏**：世界右下角是按解锁状态动态变化的 3–8 个图标 Dock（战斗 / 建设 / 种植 / 农田 / 高塔 / 装饰 / 图鉴 / 背包），战斗按钮带金色扫光和粒子点，战斗命中带火花。图标参考 Lucide（ISC）。Blockbench 是建模编辑器，ParticleEffectForUGUI 是 Unity UGUI 粒子插件，二者都不能直接作为 H5 运行时依赖；对应效果用本地 three.js/CSS 实现。
- **引擎**：three.js r120（MIT），本地打包，WebGL 1 / Chrome 61 基线；DPI 固定 1、无实时阴影、雾化远景、实例化/合批场景物件。
- **完全离线**：所有素材在 zip 内；运行时不使用 fetch/XHR，模型由包内 PNG 图片解码，头像由包内图片加载；three.js 的通用加载器类未被调用。
- **存档**：小工具 Storage API（9.46+）自动保存；不支持时降级为本次会话内存档；不使用 localStorage / IndexedDB；没有服务端。

## 关于你提供的两个项目

- **Blockbench（JannisX11/blockbench）**：它是一个开源 3D 建模编辑器（桌面/网页），适合手工捏模型、导出 GLB，不是运行时模型库，不能直接打进小工具里加载。当前 34 个动物已经有 3D 模型；如果要继续改某只动物，可以在 Blockbench 里编辑并导出 GLB，再用 `tools/build-pizza-models.mjs` 的流程转成包内 PNG 资产。
- **ParticleEffectForUGUI（mob-sakai）**：这是 Unity UGUI 的粒子插件，只能在 Unity 工程里用，H5/小工具无法直接加载。它想表达的 UI 粒子效果已经用 CSS 实现：战斗按钮的金色扫光/粒子点、战斗命中的火花、按钮按压反馈；不引入 Unity 依赖。

## 关于 WFC 和 RetopoFlow

- **WaveFunctionCollapse（mxgmn）**：它是一种基于约束/邻接一致性的程序化生成算法，不是现成的 H5 运行时库。上一版曾借鉴“约束一致性”做自动成簇摆放；这次按要求改成空岛 + 玩家自由种植，自动植被生成已移除，合法性约束只保留在“不能种到小路/水面/建筑/已有植物”这一层，把布局权交还给玩家。
- **RetopoFlow（CGCookie）**：它是 Blender 的拓扑重做插件，只能在 Blender 里用，H5 运行时无法调用。模型侧用可自动化的方式兜底：英雄图按整体包围盒取景、逐像素 QA 检查空图和四边裁切、删除九尾狐浮空金点；更深的拓扑清理仍需要在 Blender/RetopoFlow 里对源模型手工处理。
